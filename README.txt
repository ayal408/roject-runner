Project Runner 1.0 — מפעיל פרויקטים ל-Windows 10/11, 64 bit

הפעלה: חלצי את כל הקבצים ולחצי פעמיים על ProjectRunner.exe.
התוכנה עצמה אינה דורשת Python, Node או התקנה.
הפרויקטים עצמם דורשים את כלי הפיתוח המתאימים: Node / Python / .NET / Docker.

1. Browse: בחרי תיקיית פרויקט.
2. Detect: הצעת פקודה לפי קבצים בתיקייה. בדקי וערכי לפני ההרצה.
3. Run: הרצת הפקודה עם פלט ושגיאות בחלון.
4. אפשר להריץ כמה פקודות במקביל, למשל שרת ולקוח מתיקיות שונות.
5. Stop tasks: עצירת כל התהליכים שהופעלו דרך התוכנה.
6. Docker stop: הרצת docker compose down עבור התיקייה שנבחרה, ללא מחיקת volumes.
7. VS Code: פתיחת התיקייה בעורך; פקודת code צריכה להיות מוגדרת ב-PATH.
8. Folder: פתיחת תיקיית הפרויקט.

בחירת תיקיות נשמרת בחשבון Windows שלך תחת LocalAppData/ProjectRunner.
שמות תיקיות בעברית ורווחים נתמכים. אין צורך לשנות מדיניות PowerShell.
הפקודות פועלות ללא קלט אינטראקטיבי. פקודה שמבקשת סיסמה או תשובה יש להריץ בטרמינל.
עצירת Docker CLI אינה בהכרח עוצרת קונטיינרים; לכך יש Docker stop.
פלט מסומן במזהה תהליך כדי להבחין בין הרצות. פלט ישן נחתך כשנאסף הרבה טקסט.
קוד יציאה שאינו 0 מציין בעיה: העתיקי את הטקסט מהחלון ושלחי לבדיקה.

זו גרסה חדשה, לא תיקון של החבילה הקודמת שלא נמצאה.
ה-EXE נבנה בלינוקס עבור Windows. בדיקה במחשב Windows אמיתי עדיין נדרשת.
הקוד המלא מצורף בתיקיית source. בנייה חוזרת עם MinGW-w64:
x86_64-w64-mingw32-g++ -std=c++17 -O2 -static -municode -mwindows source/main.cpp -o ProjectRunner.exe -lshell32 -lole32 -luuid
